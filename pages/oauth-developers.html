TECHNOVA IDENTITY PLATFORM

Continue with TechNova

TechNova can act as an OAuth 2.1 and OpenID Connect identity provider. Registered applications can let their users sign in with an existing TechNova account using Authorization Code + PKCE.

OIDC discovery

OIDC-compatible clients can discover the provider configuration here.

https://maxlbgiomkdfynnjoghs.supabase.co/auth/v1/.well-known/openid-configuration

Issuer

Use this as the TechNova identity issuer.

Token endpoint

https://maxlbgiomkdfynnjoghs.supabase.co/auth/v1/oauth/token

UserInfo endpoint

https://maxlbgiomkdfynnjoghs.supabase.co/auth/v1/oauth/userinfo

JWKS endpoint

https://maxlbgiomkdfynnjoghs.supabase.co/auth/v1/.well-known/jwks.json

Supported identity scopes

openid profile email phone

Each client application needs its own registered Client ID and exact redirect URI. Public browser and mobile clients should use PKCE with the S256 challenge method.

Client registrations are controlled by TechNova. Do not place a confidential client secret in browser JavaScript or a public repository.
