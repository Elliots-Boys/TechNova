# Recovered Supabase migration archive

This directory contains SQL statements read from the Supabase project's `supabase_migrations.schema_migrations` history.

**Safety:** This is an archival recovery copy only. It is deliberately stored outside `supabase/migrations/` so Supabase CLI does not treat these files as active migrations. No existing migration files were modified or deleted. No SQL from this archive was executed.

Recovered remote migration versions: 29.

Files use the exact remote migration version and name: `<version>_<name>.sql`.

Before moving any file into the active migrations directory, compare it with existing local files and confirm the intended migration workflow.
