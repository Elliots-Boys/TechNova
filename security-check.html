Security Centre

A small, safe set of browser checks for the TechNova website. It checks transport security, selected response headers and whether known page routes respond. It does not attempt logins, change data, or test access by bypassing permissions.

Important: A page returning HTTP 200 only means its HTML route responded. It does not prove that its data or administrator actions are accessible. Database permissions and admin authorization require separate verification.

🔒 Connection

🛡️ Response headers

📄 Page routes

Requests the known admin page HTML without sending your sign-in cookies.

👤 Permissions
