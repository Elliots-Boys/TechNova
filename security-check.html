Security Centre

A safe diagnostic page for TechNova. Stage 1 checks browser and website configuration. Stage 2 validates your own sign-in and administrator role, then makes limited read-only requests to confirm that admin-only database access is enforced.

Safety: This page never changes database records, calls write functions, tests other users' accounts, or attempts to bypass permissions. It does not display your user ID, email, tokens or private records.

Connection, response headers and static page routes. A page route responding does not prove its data is accessible.
